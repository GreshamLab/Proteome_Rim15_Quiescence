# Supplemental Table Legends

Sun et al., "Rim15 orchestrates mitochondrial and cytoplasmic remodeling in
quiescent *Saccharomyces cerevisiae* cells." PLOS Genetics.

Tables S3 and S4 are available in the journal submission package. Table S1
(122 MB) is regenerated by `01_data_preparation_qc.Rmd`. All other tables are
in this folder and are regenerated by `make_final_supplemental_tables.R`.

---

**Table S1. All protein SILAC quantification data, long format.**
Complete protein-level SILAC quantification for all detected proteins across
all samples, in long format. Each row represents one measurement (one data
type for one protein in one sample). Columns: *Protein IDs* — UniProt
accession(s), semicolon-delimited for protein groups; *Gene names* — standard
SGD gene name(s); *Protein names* — full UniProt protein name; *Fasta headers*
— complete FASTA header from the UniProt reference proteome
(UP000002311_559292); *nutrient* — starvation condition (C = carbon,
N = nitrogen, P = phosphorus); *samplingTime* — timepoint of collection
(T00, T06, T16, T30 corresponding to 0, 6, 16, 30 h post nutrient removal);
*replicate* — biological replicate identifier (R1, R2, R3); *genotype* —
strain (WT = prototrophic wild type, rim15KO = *rim15Δ* mutant, spike-in =
common reference); *data* — measurement type (intensity = raw MS1 intensity,
normed_intensity = spike-in-normalized intensity, ratio = raw SILAC ratio
relative to spike-in, normed_ratio = normalized SILAC ratio); *value* —
numeric value for the corresponding data type. 551,664 rows total.

---

**Table S2. All phosphosite SILAC quantification data, long format.**
Normalized SILAC ratios for all 5,056 detected phosphosites across all
samples, in long format. Assembled by pivoting the wide-format Table S6.
Each row represents one phosphosite measurement in one sample. Columns:
*pSite* — phosphosite identifier in GENE_position format (e.g., IGO2_64);
*Proteins* — UniProt accession(s) of the host protein; *Leading proteins* —
primary UniProt accession used for mapping; *Gene names* — standard SGD gene
name; *Protein names* — full UniProt protein name; *genotype* — strain
(rim15KO = *rim15Δ*, WT = wild type); *nutrient* — starvation condition
(C = carbon, P = phosphorus; note that nitrogen starvation was not profiled
by phosphoproteomics); *timepoint_h* — timepoint in hours (0, 6, 16, 30);
*replicate* — biological replicate (R1, R2, R3); *normalized_ratio* —
MaxQuant-normalized SILAC ratio of the phosphopeptide relative to the common
mid-log spike-in reference (WT or rim15KO channel / spike-in). This ratio
reflects phosphopeptide abundance and is **not** corrected for changes in total
protein abundance; it therefore conflates changes in phosphorylation
stoichiometry with changes in protein level. To isolate occupancy changes,
subtract the corresponding protein log2FC (Table S16) from the phosphosite
log2FC. 242,688 rows total.

**Table S5. Normalized protein SILAC ratios, wide format.**
Normalized SILAC ratios for 1,276 proteins detected across all conditions,
in wide format. Each row is one protein; each data column is one sample.
Columns: *Protein IDs* — UniProt accession; *Gene names* — standard SGD gene
name; remaining columns — normalized SILAC ratio for each sample, named
genotype_nutrient_timepoint_replicate (e.g., rim15KO_C_T00_R1 = *rim15Δ*
carbon starvation 0 h replicate 1; WT_P_T30_R2 = wild type phosphorus
starvation 30 h replicate 2). Values are ratios relative to the common mid-log
spike-in reference; NA indicates the protein was not quantified in that sample.
1,276 rows × 74 sample columns.

**Table S6. Normalized phosphosite SILAC ratios, wide format.**
Normalized SILAC ratios for 5,056 phosphosites, in wide format. Each row is
one phosphosite; each data column is one sample. Columns: *Proteins* — UniProt
accession(s); *pSite* — phosphosite identifier (GENE_position); *Leading
proteins* — primary UniProt accession; *Gene names* — standard SGD gene name;
*Protein names* — full protein name; remaining columns — normalized SILAC
ratio per sample, named genotype_nutrient_timepoint_replicate. Carbon (C) and
phosphorus (P) starvation only; the additional columns *WT/rim15KO_C_T*…
contain pre-computed genotype ratios (WT channel / rim15KO channel). Values
are NA where a site was not quantified. 5,056 rows × 72 sample columns.

**Table S7. ANCOVA results for genotype and nutrient effects on protein
abundance.**
Linear model (ANCOVA) coefficients testing the effect of genotype and nutrient
on normalized SILAC ratios, with sampling time as a covariate. Each row
reports one model term for one protein in one condition. Columns: *Protein IDs*
— UniProt accession; *Gene names* — standard SGD gene name; *comparison* —
model type ("genotype (per nutrient)" tests WT vs *rim15Δ* within each
starvation condition; "nutrient (per genotype)" tests C vs P within each
genotype); *condition* — starvation condition or genotype for which the model
was fit; *term* — regression term (genotypeWT or nutrientP = main effect
coefficient; samplingTime = time covariate; interaction terms = time × genotype
or time × nutrient); *estimate* — regression coefficient; *std.error* —
standard error; *statistic* — t-statistic; *p.value* — nominal p-value;
*qvalue* — Benjamini–Hochberg FDR-corrected q-value; *df* — degrees of freedom
(reported for ANOVA-style rows only). 11,492 rows.

**Table S8. WGCNA module membership, wide format.**
Module assignments for 927 proteins detected in the WGCNA co-expression
analysis, in wide format. Four separate weighted gene co-expression networks
were constructed: WT carbon starvation (C_WT), *rim15Δ* carbon starvation
(C_rim15), WT phosphorus starvation (P_WT), and *rim15Δ* phosphorus starvation
(P_rim15). Columns: *Protein IDs* — UniProt accession; *Gene names* — standard
SGD gene name; *C_WT_module*, *C_rim15_module*, *P_WT_module*,
*P_rim15_module* — color-coded module label in each network (e.g., "blue",
"turquoise", "brown"); NA indicates the protein was not included in that
network (below detection threshold). 927 rows.

**Table S9. SILAC isotope incorporation, label validation experiment.**
Normalized SILAC ratios from the label-incorporation validation experiment used
to confirm that prototrophic cells incorporate heavy and medium SILAC amino
acids comparably to auxotrophic cells, and that *rim15Δ* cells are
quantitatively comparable to WT. Source data for Fig. 1B and Fig. S1A–C.
Contaminants and decoy sequences are excluded. Columns: *Protein IDs* —
UniProt accession(s); *comparison* — experimental pairing
(ProtoWT_H_vs_AuxoWT_H = prototrophic WT grown in heavy medium vs.
auxotrophic WT grown in heavy medium; ProtoWT_M_vs_AuxoWT_M = same comparison
in medium-isotope channel; ProtoWT_H_vs_rim15_M = prototrophic WT heavy
channel vs. *rim15Δ* medium channel); *normalized_ratio* — MaxQuant normalized
SILAC ratio computed across all peptide-level evidence from both experimental
runs simultaneously (peptide-median approach); more robust than per-replicate
ratios and is the value used in the figures.

**Table S12. 1N DNA content percentage per genotype, condition, and
timepoint.**
Mean percentage of cells with 1N DNA content (G1 phase) quantified by SYTOX
Green flow cytometry, averaged across biological replicates. Source data for
Fig. 1E. Columns: *Strain* — strain (WT, RIM15Δ0, DGY1 = haploid control,
DGY3 = diploid control); *Media* — starvation condition (C, N, P); *Time* —
timepoint in hours (0, 6, 16, 30, 46); *mean_pct* — mean percentage of cells
in the 1N gate across replicates; *sem_pct* — standard error of the mean.
DGY1 and DGY3 control rows have NA for Media and Time.

**Table S13. Two-way ANOVA on 1N DNA content trajectories.**
Results of two-way ANOVA (time × genotype) on the percentage of 1N cells over
the starvation time course, fit separately for each starvation condition.
Includes both ANOVA table rows and linear model coefficient rows. Source data
for Fig. 1E statistical comparisons. Columns: *Media* — starvation condition
(C, N, P); *term* — model term; *df* — degrees of freedom (ANOVA rows only);
*sumsq* — sum of squares (ANOVA rows only); *meansq* — mean square (ANOVA
rows only); *statistic* — F-statistic (ANOVA rows) or t-statistic (coefficient
rows); *p.value* — nominal p-value; *table* — source of the row ("anova" =
ANOVA decomposition, "lm_coefs" = regression coefficients); *estimate* —
regression coefficient (lm_coefs only); *std.error* — standard error
(lm_coefs only); *conf.low*, *conf.high* — 95% confidence interval bounds
(lm_coefs only). The reference level for genotype is WT; the reference level
for time is T0 (0 h).

**Table S17. Differentially expressed proteins by nutrient condition.**

**Table S21. Cross-dataset phosphosite overlap membership.**
Binary membership table indicating which Rim15-regulated phosphosites from this
study are also present in four published datasets. Phosphosites are harmonized
to SGD systematic ORF names and absolute residue positions. Source data for
the revision cross-dataset comparison figure (Reviewer points R1.3/R2.5).
Columns: *key* — site identifier (ORF_residueLetter+position, e.g.,
YNL157W_S64); *orf* — SGD systematic ORF name; *gene* — standard gene name;
*aa* — phosphorylated amino acid (S, T, or Y); *position* — position of the
phosphorylated residue in the canonical protein sequence; *ThisStudy* — 1 if
the site was detected as Rim15-dependent (q ≤ 0.05) in this study, 0
otherwise; *Li2019* — 1 if present in Li et al. 2019 (*rim15Δ*-regulated
phosphosites); *Dokladal2021* — 1 if present in Dokladal et al. 2021 (Rim15
high-confidence targets); *Baro2018* — 1 if present in Baro et al. 2018
(PP2A-Cdc55 hyperphosphorylated sites); *Plank_Cdc55AID* — 1 if present in
Plank et al. 2020 (Cdc55 auxin-depletion, nominal p ≤ 0.05); *n_published* —
number of published datasets (0–4) in which the site appears; *category* —
consensus (≥ 2 published datasets), shared (1 published dataset),
novel_this_study (0 published datasets), or published_only (not in this study).

**Table S26. Carbon starvation protein regulation overlap (this study vs Paulo et al. 2015).**
Binary membership table comparing proteins regulated during carbon starvation
in WT cells (this study) with those differentially abundant between quiescent
and log-phase cells in Paulo et al. 2015. Generated by
`revision3/R03_proteome_overlap.Rmd`. Source for this study: Table S5
(`tables/supplemental/S5_normalized_protein_ratios.csv`); WT log₂ fold
change at 30 h vs 0 h in carbon starvation; threshold |log₂FC| ≥ 1 (≥2-fold),
matching Paulo et al. 2015. Published data: Paulo et al. 2015
`NIHMS464126-supplement-3_si_003.xlsx` sheets "2X or more Up in Quiescent"
(proteins enriched in quiescent cells) and "2X or more Up in LOG" (proteins
enriched in log-phase, i.e. decreasing during quiescence entry). Columns:
*orf* — SGD systematic ORF name; *gene* — standard gene name; *ThisStudy_up*
— 1 if ≥2-fold upregulated at T30 in WT carbon starvation, 0 otherwise;
*ThisStudy_down* — 1 if ≥2-fold downregulated at T30 in WT carbon starvation,
0 otherwise; *Paulo_q_up* — 1 if ≥2-fold enriched in Paulo 2015 quiescent
fraction; *Paulo_log_up* — 1 if ≥2-fold enriched in Paulo 2015 log-phase.
